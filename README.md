# DollarFetch (BWK)

Responsive Next.js member-dashboard front-end preview.

## Run locally
Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important
This is a front-end preview only. It does not authenticate members, hold funds, process M-Pesa payments, or send withdrawals. Before real-money launch, add secure authentication, database-backed ledger logic, verified M-Pesa callbacks, and server-side administrator approval. Never put payment secrets in browser code.
